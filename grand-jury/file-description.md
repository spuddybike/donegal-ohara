## Attendance and Annotation of Members of the Donegal Grand Jury 1853-1883

### Source

The file has been constructed by transcribing records from Donegal Grand Jury Presentment books online at the [Donegal County Records](https://www.donegalculture.ie/en/services/archives/digitised-collections/donegal-grand-jury).

### Annotation

- **Position**: This is a broad description of the Grand Juror's Position (Land Owner / Freehold)
- **Relationship**: Captures the Relationship between jurors - Currently this is familial, it could be further elaborated by political affiliation as described by Emma Wright, see below.
- **Born**: Year of Birth
- **Died**: Year of Death
- **Notes**: Short biographical information
- **Link**: Link to sources for biography
- **Dated Columns**: 1 - Indicates Attendance, 2 - High Sheriff
- **Count** Number of Attendances

## Data quality issues

- The present file is a Work in Progress / under-construction, in some cases birth/death information and known attendance are contradictory
- Biographical information is available for @30 of attendees
- Name transcription is an ongoing process
- Duplication of names makes it difficult to be sure that the same ID is associated with the correct attendance
